# Монітор тривог

Онлайн-монітор повітряних тривог зі звуками та картою. Друзі відкривають посилання й одразу бачать живі дані, нічого вводити не треба.

Схема: **сторінка на GitHub Pages** (безкоштовно) + **Cloudflare Worker** (безкоштовно), який тримає токен у секреті й проксує запити до Ukraine Alarm. Токена немає ні в репозиторії, ні в браузері.

## Налаштування (один раз, ~10 хвилин)

### 1. Cloudflare Worker
1. Зареєструйтесь на dash.cloudflare.com → **Workers & Pages** → **Create** → **Create Worker** → дайте ім'я (наприклад `tryvoha`) → **Deploy**.
2. **Edit code** → видаліть усе й вставте вміст `worker/worker.js` → **Deploy**.
3. **Settings → Variables and Secrets → Add**: тип **Secret**, назва `TRYVOHA_TOKEN`, значення — ваш токен → **Deploy**.
4. Перевірте в браузері `https://tryvoha.<ваш-піддомен>.workers.dev/proxy/status`: має бути `{"hasToken":true}`.

### 2. Сторінка
1. Відкрийте `index.html`, знайдіть рядок `var PUBLIC_PROXY="";` і впишіть адресу:
   `var PUBLIC_PROXY="https://tryvoha.<ваш-піддомен>.workers.dev/proxy/ukrainealarm";`
2. Додайте поруч свою папку `assets/` (звуки та ресурси).
3. Залийте на GitHub: `git init`, `git add .`, `git commit`, `git push`.
4. У репозиторії: **Settings → Pages → Deploy from a branch → main / root**.
5. Через хвилину сайт буде на `https://<ваш-логін>.github.io/<репозиторій>/`. Це посилання й надсилайте людям.

## Локальний запуск (за бажанням)
`Start.bat` (Windows) або `./Start.sh` (Ubuntu): локальний сервер із доступом з вашої мережі. Токен — у файлі `token.txt` (скопіюйте з `token.txt.example`, він у `.gitignore`).

## Безпека й ліміти
- Токен не потрапляє в браузер і репозиторій. Не додавайте `token.txt` у git.
- Worker віддає лише читання `regions` та `alerts`, а відповіді кешує на 10 с, тож навіть багато відвідувачів роблять не більше одного запиту на 10 с до сервісу.
- Адресу Worker побачать усі, хто відкриє сайт, і зможуть дивитись ті самі публічні дані тривог. Якщо хтось зловживатиме, змініть токен у Cloudflare, і нічого більше змінювати не треба.
- Безкоштовний ліміт Cloudflare Workers: 100 000 запитів на добу.
